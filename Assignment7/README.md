# Superstore Dataset — Pandas Data Exploration & Cleaning

## Objective
Learn Python basics and perform basic data exploration and cleaning using Pandas, using a
Superstore-style sales dataset (based on the Kaggle dataset
[`vivek468/superstore-dataset-final`](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)).

## What this project does
1. Load a CSV dataset into a Pandas DataFrame
2. Explore the data (`head`/`tail`, `shape`, `columns`, `dtypes`, `info`, `describe`)
3. Identify and handle missing values (median fill for numeric columns, mode fill for categorical columns)
4. Perform basic operations — filter rows (e.g. high-value Technology orders, Same Day shipments) and
   select columns
5. Remove duplicate rows
6. Create a derived column: `total_amount = Price * Quantity`
7. Save the cleaned dataset to a new CSV

## About the data
This repo ships with `data/superstore_raw.csv`, a **synthetic dataset generated to mirror the schema of
the real Kaggle Superstore dataset** (same column structure: Order ID, Order/Ship Date, Ship Mode,
Customer info, Segment, Region/State/City, Category/Sub-Category, Product Name, Price, Quantity,
Discount), with missing values and duplicate rows deliberately injected so every cleaning step in the
notebook has something real to fix.

> **To use the real Kaggle dataset**: download it from the link above, save it as
> `data/superstore_raw.csv` (replacing the sample file, and renaming/mapping columns to match if needed),
> then re-run the notebook top to bottom. The pipeline works identically either way.

## How to run
```bash
pip install pandas jupyter
cd notebooks
jupyter notebook data_cleaning_assignment.ipynb
```
Run all cells top to bottom. The cleaned CSV will be written to `data/superstore_cleaned.csv`.

## Results
- Raw dataset: 520 rows × 16 columns, with missing values across `Price`, `Quantity`, `Discount`,
  `Ship_Mode`, and `Customer_Name`, plus 20 duplicate rows.
- Cleaned dataset: 500 rows × 17 columns (added `total_amount`), 0 missing values, 0 duplicates.
